How to view
----------
1. the is no installation needed
2. just double-click any .HTML file on the reporsitory and it will open in your default browser(Chrome, Edge, Safari,etc)


Files
------
1. sitemap.html
   -this file has the visual map of the whole PHP/MySQL project,the login gateway, client dashboard, admin console and the supporting backend scripts.

2.Standard XML sitemap (sitemaps.org protocol) listing the public, crawlable pages only (login/dashboard/ admin excluded since they
require authentication). This file is not meant to be "run" or viewed visually — opening it in a browser will simply display the
raw XML tags, which is expected. It is the machine-readable version used by search engines and site crawlers.
